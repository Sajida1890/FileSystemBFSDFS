# File System Representation and Search Using BFS and DFS

## Activity Details
- Activity: Challenge 17-B 09
- Activity ID: SY-S3-B-09
- Subject: Data Structures and Algorithms
- Language: C

## Objective
To represent a file system as a graph using an adjacency matrix and search for files using BFS and DFS algorithms.

## Concepts Used
1. Graph
2. Adjacency Matrix
3. Breadth First Search (BFS)
4. Depth First Search (DFS)
5. Queue
6. Recursion
7. Visited Array

## How to Compile
gcc main.c -o filesystem.exe

## How to Run
filesystem.exe

## Sample Test
Starting node: Root
Search file: Notes.txt

Expected result:
File found using BFS!
File found using DFS!

## Conclusion
The program successfully represents a file system
using a graph and searches for files using BFS and
DFS algorithms.
